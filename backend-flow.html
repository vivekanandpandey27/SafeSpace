🔒 Middleware Reference
Auth
authAdmin
Reads atoken from request headers. Verifies JWT via JWT_SECRET. Checks decoded payload for role === 'admin' and matching email. Blocks with 401 if invalid.
Auth
authDoctor
Reads dtoken from request headers. Verifies JWT and decodes id. Attaches doctor ID to req.user so downstream controller knows which doctor is acting.
Auth
authUser
Reads token from request headers. Verifies JWT and decodes user id. Attaches to req.body.userId so controllers can identify the authenticated user.
File Upload
multer (upload)
Configured for diskStorage. Used as upload.single('image') to parse a single image file from multipart/form-data. Exposes the file on req.file.
